언더다크 DB 데이터 관리

모든 게임 데이터는 연동된 구글 스프레드시트에서 실시간으로 안전하게 관리됩니다.

🚀
구글 스프레드시트 바로가기
새 창에서 시트를 열고 영웅, 지원용병, 탈것, 펫 정보를 자유롭게 수정하세요.
💡 데이터 수정 및 웹사이트 반영 절차
  1. 아래 [구글 스프레드시트 열기] 버튼을 눌러 시트에서 데이터를 수정합니다.
  2. 수정 내용은 구글 클라우드에 실시간 자동 저장됩니다.
  3. 웹사이트 반영 시 프로젝트 폴더의 sync_sheets.bat 파일을 더블클릭합니다.
  4. 1초 만에 웹사이트의 모든 데이터가 최신 상태로 갱신됩니다!
